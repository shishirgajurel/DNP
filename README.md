# C# / .NET exercises (DNP course)

Exercises from the **DNP (.NET) course** at VIA University College, written while learning C# and .NET.

## Contents
| Project | What it practises |
|---|---|
| `VIA` | Products and categories, calculating prices including VAT with a small utility class |
| `AbbaApp`, `Excersise 8`, `Excersise 9` | String manipulation (building, wrapping and filtering strings) |
| `Excersise 3` | Classes, properties and object initializers (`Person`) |
| `Excersise 4` | Loops and methods (even/odd numbers) |
| `Excersise 5`, `Excersise 6` | A `Calculator` class, including reading user input |
| `Excersise 10`, `Excersise 11` | Array algorithms (largest difference, counting clumps) |

All projects are in one solution: `VIA.sln`.

## Run it
Requires the **.NET SDK**.
```bash
dotnet run --project VIA
```
Or open `VIA.sln` in JetBrains Rider / Visual Studio and run any project.
